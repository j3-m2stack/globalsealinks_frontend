## 🛠️ Technical Architecture

### Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Font**: Inter (Google Fonts)

### Component Structure
```
components/
├── Navbar.tsx          # Navigation with language switcher
├── Hero.tsx            # Hero section
├── About.tsx           # Features grid
├── Products.tsx        # Products showcase
├── ExportProcess.tsx   # Timeline
├── Imports.tsx         # Imports section
├── GlobalReach.tsx     # World map
├── Testimonials.tsx    # Reviews carousel
├── Contact.tsx         # Contact form
├── Footer.tsx          # Footer
└── WhatsAppButton.tsx  # Floating button
```

### State Management
- **LanguageContext**: Global language state
- **localStorage**: Persist language preference
- **useState**: Local component state
- **useEffect**: Side effects and lifecycle

### Performance Features
- Server-side rendering (SSR)
- Static generation where possible
- Lazy loading with Framer Motion
- Optimized images
- Code splitting
